# Аттестация: даты и связанные события

HR или администратор задаёт дату проведения в модуле «Аттестация». Для активного
сотрудника автоматически создаются два мероприятия: подготовка документов и
проведение аттестации. Подготовка назначается ровно за 14 календарных дней до
проведения; выходные не меняют расчёт, прошедшие сроки показываются просроченными.

В таблице доступны ФИО, дата подготовки документов и дата проведения. По нажатию
на строку открывается окно изменения даты. После сохранения оно показывает
пересчитанную дату подготовки и статус проведения. Кнопка «Мероприятие» открывает
связанное проведение: здесь можно выполнить, отменить или переоткрыть его.
Перед изменением статуса нужно сохранить изменённую дату.

В «Все мероприятия» дата проведения редактируется в той же карточке, в том числе
после выполнения. Исправление обновляет обе даты, сохраняя факт выполнения,
автора, время регистрации выполнения и историю. Дата подготовки отдельно не
редактируется. Выполнение одного мероприятия не выполняет второе.

Очистка даты отменяет открытые мероприятия и сохраняет завершённые. Повторная
установка восстанавливает мероприятия, отменённые при очистке. Явная отмена
пользователем сохраняется до переоткрытия. Пока дата отсутствует или сотрудник
неактивен, изменять связанные мероприятия нельзя. Viewer может читать таблицу,
но не менять даты и статусы.

Перенос обновляет ожидающие уведомления; уже отправленные сообщения остаются в
журнале. Отдельные правила для двух типов можно выбрать в настройках Nextcloud.

## Обновление установленного приложения

Обновите backend и соберите frontend совместно. Новая миграция схемы не требуется:
используются существующая дата в Employment, события и их статусы.

Для дат, введённых до обновления, один раз запустите штатный rule engine с
настройками нужного окружения. В установке с systemd после обычного обновления:

```bash
sudo systemctl start bookuchet-rules.service
```

В настроенном CLI-окружении можно ограничить запуск компанией:

```bash
flask --app wsgi:app run-rules --company-id <company_id>
```

Команда выполняется из backend с переменными нужного контура; она пересчитывает
все правила выбранной компании. Существующая дата не считается подтверждением
проведения: HR отмечает выполнение явно. Периодичность и автоматическое назначение
следующей аттестации не добавлены.
