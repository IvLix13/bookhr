# Формат импорта Excel

Версия шаблона: `2.0`

## Обязательные колонки

| Колонка | Поле | Описание |
|---|---|---|
| ФИО | full_name | Полное имя сотрудника |
| Начало работы | hire_date | Формат `ДД.ММ.ГГГГ` или `14 ноября 2026 г.` |

## Дополнительные колонки

| Колонка | Поле |
|---|---|
| № п/п | row_num |
| Должность | title |
| Грейд по должности | position_grade |
| Фактический грейд | actual_grade |
| ВУЗ | has_university |
| Окончание договора | contract_end |
| Дата получения текущего грейда | grade_date |
| Срок окончания паспорта | passport_until |

## Форматы дат

Поддерживаются:

- `ДД.ММ.ГГГГ` (например `14.11.2026`)
- длинный русский формат `14 ноября 2026 г.` / `14 ноября 2026`
- ячейки Excel с типом «дата»

## Правила

1. UUID в файле **не используется** и не должен присутствовать в шаблоне. Для новых сотрудников UUID генерируется системой.
2. Повторный импорт сопоставляет сотрудников по нормализованному ФИО.
3. Если найдено несколько кандидатов с одним ФИО, строка помечается как `ambiguous` — пользователь выбирает: создать нового, обновить конкретного кандидата или пропустить.
4. Пустая ячейка «ВУЗ» при обновлении не затирает уже сохранённое значение.
5. Повторный импорт не создаёт дубликаты паспортов и записей грейда с теми же датами.
6. После проверки обязателен confirm; в ответе приходит полный отчёт: создано / обновлено / пропущено (с причинами).

## Экспорт

Шаблон без UUID: `GET /api/import/template`. Даты в шаблоне выгружаются в формате `ДД.ММ.ГГГГ`.
