# Формат импорта Excel

Версия шаблона: `1.0`

## Обязательные колонки

| Колонка | Поле | Описание |
|---|---|---|
| UUID | uuid | Постоянный идентификатор сотрудника. При первом импорте может быть пустым |
| ФИО | full_name | Полное имя сотрудника |
| Начало работы | hire_date | Формат `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД` |

## Дополнительные колонки

| Колонка | Поле |
|---|---|
| № п/п | row_num |
| Должность | title |
| Грейд по должности | position_grade |
| Фактический грейд | actual_grade |
| ВУЗ | has_university |
| Окончание договора | contract_end |
| Дата получения текущего грейда | grade_date |
| Срок окончания паспорта | passport_until |

## Правила

1. При первом импорте для новых сотрудников генерируется UUID.
2. Повторный импорт обновляет запись только по UUID.
3. Если UUID отсутствует, выполняется сопоставление по нормализованному ФИО.
4. Неоднозначные строки попадают в dry-run как `ambiguous`.
5. Подтверждение импорта обязательно после проверки.

## Экспорт

После импорта доступен шаблон с UUID через `GET /api/import/template`.
